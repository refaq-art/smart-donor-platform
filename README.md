# مستشار الدعم الذكي للجمعيات

تم إنشاء نسخة مجانية من الموقع داخل ملف `index.html`.

## تشغيل الرابط العام عبر GitHub Pages

من صفحة المستودع:

1. ادخل إلى Settings.
2. ادخل إلى Pages.
3. اختر Source: Deploy from a branch.
4. اختر Branch: main.
5. اختر Folder: /root.
6. اضغط Save.

بعد دقيقة تقريبًا سيظهر الرابط:

https://refaq-art.github.io/smart-donor-platform/

## ملاحظات

- البيانات تحفظ داخل المتصفح فقط LocalStorage.
- هذه نسخة مجانية للتجربة ولا تحتاج Lovable أو مفاتيح مدفوعة.
- لا ترفع بيانات حساسة قبل ربط قاعدة بيانات حقيقية.
