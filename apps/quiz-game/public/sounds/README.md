# ملفات الصوت

هذه الملفات مؤثرات صوتية بسيطة (نغمات مُولَّدة برمجيًا عبر `scripts/generate-sounds.py`، بدون أي حقوق ملكية
أو اعتماديات خارجية) — تعمل فورًا دون أي إعداد إضافي:

| الملف | الاستخدام |
|---|---|
| `tick.wav` | نقرة عد تنازلي كل ثانية |
| `countdown.wav` | آخر 3 ثوانٍ من المؤقت |
| `correct.wav` | إجابة صحيحة |
| `wrong.wav` | إجابة خاطئة |
| `win.wav` | الفوز بالمباراة |
| `click.wav` | نقرات الواجهة العامة |
| `levelup.wav` | ارتفاع صعوبة السؤال (Adaptive Difficulty) |
| `bg-music.wav` | موسيقى خلفية اختيارية (تُفعَّل يدويًا من زر الصوت) |

## لاستبدالها بمؤثرات احترافية لاحقًا

هذه نغمات بسيطة كافية للتجربة، وليست بديلاً نهائيًا عن تصميم صوتي احترافي. لتحسينها لاحقًا:

1. حمّل مؤثرات صوتية مجانية من مواقع مثل freesound.org أو mixkit.co (تحقق من الترخيص قبل الاستخدام التجاري).
2. استبدل الملفات بنفس الأسماء أعلاه (mp3 أو wav تعمل كلاهما — عدّل الامتداد في
   `src/components/providers/sound-provider.tsx` إذا غيّرت الصيغة).

لإعادة توليد النغمات الافتراضية: `python3 scripts/generate-sounds.py`
