# ملفات الصوت المطلوبة

النظام جاهز بالكامل للصوت (تشغيل/كتم، موسيقى خلفية اختيارية) لكنه لا يتضمن ملفات صوتية فعلية
(حقوق ملكية/حجم الملفات الثنائية). أضف ملفات mp3 قصيرة بهذه الأسماء داخل هذا المجلد ليعمل الصوت تلقائيًا
بدون أي تعديل في الكود — النظام يتجاهل الأخطاء بصمت إن كانت الملفات غير موجودة:

| الملف | الاستخدام |
|---|---|
| `tick.mp3` | نقرة عد تنازلي كل ثانية |
| `countdown.mp3` | آخر 3 ثوانٍ من المؤقت |
| `correct.mp3` | إجابة صحيحة |
| `wrong.mp3` | إجابة خاطئة |
| `win.mp3` | الفوز بالمباراة |
| `click.mp3` | نقرات الواجهة العامة |
| `levelup.mp3` | ارتفاع صعوبة السؤال (Adaptive Difficulty) |
| `bg-music.mp3` | موسيقى خلفية اختيارية (تُفعَّل يدويًا من زر الصوت) |

يمكنك تحميل مؤثرات صوتية مجانية من مواقع مثل freesound.org أو mixkit.co (تحقق من الترخيص قبل الاستخدام التجاري).
